# 上线检查清单

## 自动检查

```powershell
npm run release:check -- -EnvFile .env.production
```

- 锁定依赖安装、Prisma Client 生成、类型检查、全部测试和生产构建通过。
- Compose 配置、镜像构建、迁移和容器健康检查通过。
- `/health/ready` 返回 200。
- PostgreSQL 备份可恢复到独立验证数据库。
- 源码中不存在演示密码、原型仓库或业务 `localStorage`。

## 上线前人工检查

- DNS 已指向服务器，HTTPS 证书有效且自动续期。
- `APP_ORIGIN` 与正式 HTTPS 域名完全一致。
- 数据库密码、`COOKIE_SECRET`、管理员密码均存储在密码管理器中。
- 首次启动日志确认管理员已创建；随后已从 `.env.production` 删除或清空管理员引导密码。
- 防火墙只开放必要的 HTTP/HTTPS 和运维入口；PostgreSQL 未映射公网端口。
- 已创建首个管理员和唯一工作室，两个私密入口已保存。
- 已实际完成一次：用户注册与登录 → 提交两条链接 → 工作室扫码、成功/失败反馈与下一个任务 → 用户查看结果 → 管理员停用用户。
- 已确认异机或对象存储备份同步正常。
- 已记录当前 Git 提交、镜像摘要和回滚命令。

## 上线后观察

- 观察 API/Nginx 错误日志、数据库连接和磁盘空间至少 30 分钟。
- 检查排队数、处理中数和成功/失败结果是否与操作一致。
- 验证旧注册链接或工作室入口轮换后确实失效。
